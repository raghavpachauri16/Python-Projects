# 🚀 Python Projects Collection

A collection of beginner-friendly Python GUI projects built with Tkinter, demonstrating desktop app development, data persistence, input validation, and interactive UI design.

---

# 📌 Projects Included

## 1. 📇 Contact Book

A simple, user-friendly contact management app built with Tkinter.

### Features

* ➕ Add Contact (name, phone, email, address)
* 📋 View Contacts
* 🔍 Search by Name or Phone
* ✏️ Update Contact
* ❌ Delete Contact
* 💾 Persistent Storage (JSON)
* ✅ Input Validation
* 🔔 Toast Notifications

### Technologies Used

* Python
* Tkinter
* JSON
* Regex (re)

---

## 2. ✂️ Rock Paper Scissors

A polished Rock-Paper-Scissors game built with Tkinter.

### Features

* 🖱️ Click to Play (Rock, Paper, or Scissors)
* 🤖 Random Computer Moves
* ⚔️ Face-to-Face Battle Box UI
* 🟢 Win/Loss/Tie Highlighting
* 🧮 Running Score Tracker
* 🔁 Reset Score
* 🎨 Custom Dark Theme

### Technologies Used

* Python
* Tkinter
* Random Module

---

## 3. 🧮 Simple Calculator

A basic calculator built with Tkinter for everyday arithmetic.

### Features

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Python-Tkinter-Projects.git
```

Move into the project folder:

```bash
cd Python-Tkinter-Projects
```

No external libraries are required — all three projects use only Python's standard library. On Linux, you may need to install Tkinter separately:

```bash
sudo apt install python3-tk
```
